# UniverseLab

This repository now includes a starter n-body gravity simulation for the **Sun, Earth, and Moon**.

## Run the simulation

```bash
python /home/runner/work/UniverseLab/UniverseLab/gravity/earth_sun_moon_simulation.py
```

Outputs:

- `/home/runner/work/UniverseLab/UniverseLab/datasets/earth_sun_moon_trajectories.csv`
- `/home/runner/work/UniverseLab/UniverseLab/visualizations/earth_sun_moon_simulation.svg`
